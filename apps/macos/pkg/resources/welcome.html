言外 Subtext —— 双语输入法

安装后会把「言外」加进系统的输入法列表并自动启用，之后在输入法菜单里切换即可。

  • 读得懂潜台词：复制一段英文，自动解码语气、俚语与言外之意，译文先折叠，让你先自己猜。
  • 写得出地道话：打完一句中文，给出可直接发送的英文，并说明为什么这样说。
  • 候选词右侧显示词性与译文，拼音、词库、学习全部离线。
  • 双语教练默认关闭；在偏好设置的「双语教练」里选好后端（本机 Claude Code / Codex，或你自己的 API）才会启用。启用后复制的英文与上屏的中文会发给你选的后端，密码框与疑似密钥的内容不会发送。
  • 用户词频与配置保存在「~/资源库/Application Support/Subtext/」，输入日志只写本机，用于离线评测，可在偏好设置里关闭或清空。

安装到「/资源库/Input Methods/」，需要管理员密码。本安装包使用 ad-hoc 签名，首次打开请在「系统设置 → 隐私与安全性」里点「仍要打开」。
