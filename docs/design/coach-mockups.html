A · 注释卡（跟光标，最轻）

像候选窗的延伸：选中文字按快捷键，卡片浮在光标下。不抢焦点，Esc 即收。适合快速读一条消息。

解码 · 同事在催你，但催得很客气
no rush at all套话字面「不急」，实际是软化催促。真不急的人不会专门提
PR生词pull request，GitHub 上提交合并的请求
lmk缩写let me know
just merge it给你台阶，也在暗示「你再不看我就自己合了」
语气：友好，带 deadline 压力（dev 圈标准客气话）

B · 侧栏教练（三模式 + 先猜后看）

贴右边的固定面板，三个 Tab 对应你 Skill 的 A/B/C。译文默认折叠，点开才看，保留「先不给翻译」的规则。

解码组句改稿
同事在催你，但催得很客气
no rush at all软化催促的套话；中文「不着急哈」通常是真不急，英文这句更多是在催
lmklet me know　你可以这样用lmk if the board arrives
just merge it台阶 + 暗示
先自己猜一下意思，再点开看译文 ›嘿——不急哈，不过你看过那个 PR 了吗？要是你愿意，我就直接合了。
语气：友好 + 轻 deadline 压力　·　国内类比：微信里的「不急哈～」

C · 原文高亮（读原文为主）

把整条消息摆出来，难点下划线着色（橙=俚语 / 青=软化 / 灰=缩写），点哪个展开哪个。信息量最大但最占地方。
