# 使用说明

## 输入法本身

Subtext 的拼音输入法部分沿用青简的内核：整句输入、简拼、拼写纠错、双拼、五笔、自定义短语、本地整句模型。
候选旁显示一条译词，学习语言在偏好设置 → 常规里选（英语 / 日语 / 西班牙语 / 关闭）。
模糊音在偏好设置 → 模糊音里勾选（开着 z/zh、c/ch、s/sh 时，`suangyu` 这类敲不出翘舌的写法也能打出「双语」「装」「窗」）；候选窗可以直接用鼠标点选；模糊音在偏好设置 → 模糊音里勾选，可以连着勾；输入法菜单里「模糊音 → 在设置里改…」直接跳到那一页（系统菜单点一项就会收起，所以不适合连着改）。
按键与设置项以偏好设置窗口里的说明为准。

## 双语教练

### 它什么时候出现

| 你做了什么 | 教练做什么 | 面板里的操作 |
|---|---|---|
| 复制了一段英文（至少三个单词，不是链接或代码） | **解码**：情境、俚语与缩写、语气、潜台词，译文默认折叠 | 「显示译文」展开；Esc 关闭 |
| 打完一句中文，停约 1.4 秒（至少 4 个汉字） | **组句**：1–3 个按场合排好的英文，加「为什么这样说」 | ⌥1 / ⌥2 / ⌥3 用对应英文替换刚打的中文；「复制」放进剪贴板 |
| 打完一句英文，停约 1.8 秒（至少 3 个单词） | **校对**：中文意思（核对有没有打错、听错）、修正版、更地道的说法 | ⌥1 替换为修正版，⌥2 / ⌥3 替换为更地道的说法 |
| 选中一段文字，按 ⌃⌥E | 英文：**改稿**（修正版 + 逐条说明）；中文：组句 | ⌥1 替换选中的文字 |

只在 **Subtext 是当前输入法** 时工作。切走输入法、进入密码框，轮询立即停止。

### 替换是怎么保证不改坏你的文字的

⌥ 数字或点「替换」时，Subtext 会先去应用里读一遍那段范围，**内容和刚才上屏的完全一致才替换**；
不一致（你又改了、应用不支持读文本）就不动应用里的内容，只把英文放进剪贴板，让你 ⌘V。

### 语气与缩写怎么定

教练按这些线索判断，拿不准时选更稳的写法：

- 当前应用：邮件类偏正式（先说事再给原因）；Discord / Slack / 信息类偏随意，可以用 `lmk`、`tmrw`；开发工具里技术圈随意但精确。
- 你最近解码过的那条对方消息（15 分钟内有效）：写回复时按它的语气接。
- 你的「学习者画像」（`profile`）：写得越贴近你，教练越对症。

### 屏幕阅读

复制、上屏之外的第四种用法：**持续读取屏幕上的一个窗口或区域**，新出现的英文自动翻译，鼠标停在哪句就解释哪句。适合看微信 / Discord / 邮件 / 网页里的一整段英文，不用来回复制。

**开始**

| 方式 | 做什么 |
|---|---|
| ⌃⌥R | 没在读：开始读**鼠标所在的窗口**；在读：停止 |
| 输入法菜单 → 屏幕阅读 → 读取鼠标所在的窗口（3 秒后） | 点完菜单会收起，留 3 秒把鼠标移到目标窗口上 |
| 输入法菜单 → 屏幕阅读 → 框选区域… | 屏幕变暗，拖出一块要读的区域；单击不拖是取消 |
| 输入法菜单 → 屏幕阅读 → 停止屏幕阅读 | 停止，并丢掉识别过的文字 |

快捷键在 `[shortcut] screen_reading`。需要先**启用双语教练**并选好后端。

**怎么工作**

1. 每隔 1.5 秒（`[coach] screen_interval_ms`）截一次图。窗口按窗口号截，被别的窗口挡住的部分也能截到；画面没变就跳过识别。
2. 用系统自带的 Vision 在本机识别文字，把折行的几行合并成「一条消息」。
3. 屏幕上出现新的英文消息，批量交给后端翻译（一次最多 5 条，流式生成）。翻译过的会记住，识别时的细微抖动（标点、个别字）不会重复翻译。
4. 鼠标在一条消息上停留约 0.35 秒，旁边弹出它的译文和一句语气 / 俚语提示。鼠标指着的那条还没翻译，会插队优先翻。

**隐私**

- 只在你按下开始之后才读；目标窗口右上角一直有「● 屏幕阅读中」的小标记，随时看得见。
- 截图识别完立刻删除。OCR 全程在本机，不联网。
- 只有识别出的**英文消息**会发给后端：汉字多的块（界面文字）、少于 3 个单词的块（按钮、昵称）、链接、代码、含验证码 / 密钥 / 口令字样的块都不发；你在 `skip_apps` 里列出的应用的窗口不读。
- 系统正在输入密码（Secure Input）时自动暂停：什么都不截、不发，悬浮卡也收起；密码输完自动恢复。停用双语教练会停止屏幕阅读。

**权限**

第一次开始时系统会请求「屏幕录制」权限：到 系统设置 → 隐私与安全性 → 屏幕录制，给 **Subtext** 打开，然后重新开始（授权后系统可能要你注销再登录才生效）。安装包是 ad-hoc 签名，**每次升级版本后系统可能要求重新授权**。

**限制**

- 竖排与单行横排之外没有区别；只翻译英文（中文消息不处理）。
- 识别会有错字（`lmk` 识成 `Imk`），模型会按上下文还原，但偶尔会翻错。
- 命令行后端翻译一批要几十秒，想要鼠标一指就有译文，建议改用 API 后端。
- 微信、Discord 这类应用窗口可以读；全屏游戏、带 DRM 的视频窗口截不到。

### 后端

在 偏好设置 → 双语教练 里选，改完点「测试连接」。

| 后端 | 说明 |
|---|---|
| 本机 Claude Code | 调用 `claude -p`，提示走标准输入（不会出现在进程列表里）。限定只读项目级配置、关闭所有工具、不留会话。需要先在终端里登录过：运行一次 `claude` 完成登录 |
| 本机 Codex | 调用 `codex exec`，回复读 `--output-last-message` 写的文件。**未在真机上验证过** |
| OpenAI 兼容接口 | `POST <地址>/chat/completions`。地址不含 `/chat/completions`。`reasoning_effort` 缺省 `none`（关思考，要快），不认这个参数的接口把它清空 |
| Anthropic API | `POST /v1/messages`，缺省模型 `claude-haiku-4-5-20251001` |

命令行后端的路径留空会自动查找（`~/.local/bin`、`/opt/homebrew/bin` 等，最后问登录 shell）。
输入法进程看不到终端里的环境变量和代理设置：用 API 后端时密钥请在偏好设置里填（存进配置目录的 `.env`）。

### 隐私边界

开启后会外发什么、什么绝不外发，见 [README 的隐私一节](../README.md#隐私)。几个实现细节：

- 闸门在发送之前统一检查：隐蔽剪贴板、`skip_apps`、长度、语言、链接 / 代码、疑似密钥。命中任何一条都不会发出请求。
- 请求在后台线程里发，主线程只往通道里丢请求、取结果，**不会拖慢打字**；积压的旧请求只保留最新一个。
- 同样的文本在同样的上下文里再来一次，直接用缓存，不再花额度。

## 配置项

配置文件 `~/Library/Application Support/Subtext/config.toml`，保存后自动生效。教练相关的全部键：

| 键 | 缺省 | 说明 |
|---|---|---|
| `[coach] enabled` | `false` | 总开关 |
| `backend` | `"claude-cli"` | `claude-cli` / `codex-cli` / `openai` / `anthropic` |
| `auto_decode` / `auto_compose` / `auto_edit` | `true` | 三个自动触发 |
| `claude_path` / `claude_model` | `""` / `"haiku"` | 路径留空自动找 |
| `codex_path` / `codex_model` | `""` / `""` | 模型留空用 Codex 缺省 |
| `openai_base_url` / `openai_model` | DeepSeek | |
| `openai_api_key_env` | `SUBTEXT_COACH_API_KEY` | 密钥所在的环境变量名；偏好设置里填的密钥写进 `.env` |
| `reasoning_effort` | `"none"` | 留空则不发这个参数 |
| `anthropic_model` | `claude-haiku-4-5-20251001` | |
| `anthropic_api_key_env` | `ANTHROPIC_API_KEY` | |
| `timeout_ms` | `90000` | 命令行后端要启动进程，给得比较宽 |
| `max_chars` | `1500` | 超过不发 |
| `screen_interval_ms` | `1500` | 屏幕阅读两次截屏的间隔（毫秒），最低 500 |
| `skip_apps` | 1Password、Bitwarden、钥匙串等 | bundle identifier 列表 |
| `profile` | 通用描述 | 学习者画像，写进给模型的说明 |
| `[shortcut] coach_selection` | `control+option+e` | 选中文字交给教练 |
| `[shortcut] screen_reading` | `control+option+r` | 开始 / 停止屏幕阅读 |

## 排错

| 现象 | 原因与办法 |
|---|---|
| 复制英文没反应 | 教练没开 / 当前输入法不是 Subtext / 文本少于三个单词、是链接或代码 / 在密码框里。看 `~/Library/Logs/Subtext/` 里的日志，开「详细日志」会记下为什么被拦 |
| 面板显示「命令行 claude 没有登录」 | 命令行的登录和 Claude 桌面 App 的登录是两套。在终端运行 `claude auth login`（Codex 是 `codex login`）授权后再试；`claude auth status` 显示 `loggedIn: true` 才算好 |
| 「没找到 claude 命令」 | 在偏好设置里填它的完整路径（终端里 `which claude`） |
| ⌥1 没有替换，只复制了 | 应用里那段文字已经变了，或这个应用不支持读文本（部分 Electron 应用、终端）。⌘V 粘贴即可 |
| 候选词只有译文、中文候选是空白 | 0.2.0 的已知问题：系统恰好在输入法启动时更新字体，输入法只拿到了画不出汉字的精简字体。升级到 0.2.1 即可；仍有问题把日志里「候选窗使用位图渲染器」那一行发来 |
| 面板一会儿就没了 | 0.2.1 及以前，切换窗口、继续打字都会收起面板。0.2.2 起只在 Esc、点「关闭」、超时（解码 10 分钟、组句 / 校对 2 分钟，鼠标停在面板上不计时）、切走输入法时收起 |
| 屏幕阅读提示要「屏幕录制」权限 | 系统设置 → 隐私与安全性 → 屏幕录制 → 打开 Subtext，再重新开始；不生效就注销再登录 |
| 屏幕阅读读不到窗口 | ⌃⌥R 取的是**鼠标所在的窗口**：先把鼠标放到目标窗口上再按；窗口太小（边长小于 120 点）、全屏游戏、DRM 视频读不了；可以改用「框选区域」 |
| 鼠标指着英文没有悬浮卡 | 悬浮卡要鼠标在那一条上停约 0.35 秒；这条要是汉字为主、少于 3 个单词、含验证码字样，就不会翻译；窗口右上角的标记会显示出错原因 |
| 回复很慢 | 命令行后端第一次要启动进程，十几秒是正常的；命令行后端实测一次要 20–40 秒（启动进程约 5 秒，其余是逐字生成），想几秒出结果请改用 API 后端（如 DeepSeek） |
