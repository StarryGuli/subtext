# 使用说明

## 窗口

菜单栏的「言」图标，或全局热键 **⌃⌥Space**，打开言外窗口。

- 上方三个按钮选模式：**读 / 写 / 改**。模式永远由你选，教练不再猜你要读还是要写。
- 打开窗口时，剪贴板里有**比上次新**的内容就带进输入框，并按语言选起始模式（含汉字 → 写，否则 → 读）。
  你正在改的输入不会被同一份剪贴板覆盖；「粘贴剪贴板」可以强制重新带入。
- **⌘↵** 解析。结果边生成边显示，生成完状态栏写「完成」；「复制结果」复制可直接发送的一段。
- 「清空」清掉输入与结果。

## 三种模式

**读**：每一句英文给一个条目：原句、中文意思、这一句里缩写 / 俚语 / 套话的提示（橙色）。
最后一句话讲语气与潜台词；只有「词典查不到」的套话、文化惯例才会另起一条（最多 2 条）。
看不到上文、指代不清的地方会直接说「这是推测」。

**写**：输入中文，或中英混着写。已经写好的英文片段原样保留，只补全中文那几截。
给 1 到 2 个可直接发的英文（标星的是推荐），加「中文的说法 → 英文的说法」对照与直译陷阱。
刚「读」过一条消息（30 分钟内）时，回复会接它的语气。

**改**：贴你写的英文。给修正版、修正后的中文意思、最多 3 条改动说明、写得好的地方、可替换的更地道说法。
全小写、`u` / `ur`、句尾 `though` 这类聊天写法不会被当成错。语音输入造成的同音词错误直接改掉，不批评。

## 配置

文件：`~/Library/Application Support/Subtext/config.toml`，只写 `[coach]` 一节，缺的项用缺省值。

```toml
[coach]
backend = "claude-cli"        # claude-cli | codex-cli | openai | anthropic
claude_model = "haiku"
max_chars = 1500              # 单次最多发多少字符
profile = "母语中文，……"       # 学习者画像，写进系统提示；写得越贴近你，教练越对症
```

密钥放 `~/Library/Application Support/Subtext/.env`：`ANTHROPIC_API_KEY=...` 或 `SUBTEXT_COACH_API_KEY=...`（OpenAI 兼容接口）。
从访达启动的应用拿不到 shell 里的环境变量，所以不能只在终端里 `export`。

## 排错

- **点了解析一直「思考中」**：本机 Claude Code 后端每次要启动一次进程，慢的时候十几秒；换 API 后端会快很多。
- **提示「没有发出去」**：闸门拦下了（空、太长、像密钥、像链接或代码），按提示改。
- **热键没反应**：⌃⌥Space 可能被别的程序占了，日志里会有「全局热键注册失败」；仍可从菜单栏图标打开。
- 日志：从终端运行 `RUST_LOG=info target/app/Subtext.app/Contents/MacOS/subtext` 能看到输出。

## 命令行试用

```bash
cargo run -p subtext-coach -- --mode decode "hey, no rush but did you look at the PR?"
cargo run -p subtext-coach -- --print-prompt "…"      # 只看会发出去的提示词
```
